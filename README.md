# C Programlama Temelleri ve Algoritma Uygulamaları

Bu depo; C programlama dili kapsamında temel sözdizimi, bellek yönetimi ve algoritma mantığını pekiştirmek amacıyla geliştirdiğim uygulamaları ve alıştırmaları içerir.

## 🎯 Kapsanan Konular
* Değişkenler, veri tipleri ve kontrol yapıları (`if-else`, `switch-case`)
* Döngüler (`for`, `while`, `do-while`) ve fonksiyon tanımlamaları
* Diziler (Arrays), karakter dizileri (Strings) ve işaretçiler (Pointers)
* Yapılar (`struct`) ve temel dosya işlemleri

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C
* **Derleyici / IDE:** GCC / Visual Studio / VS Code
* **Sürüm Kontrolü:** Git & GitHub
